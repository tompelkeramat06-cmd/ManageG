# TaskFlow — Smart College Planner

Versi premium frontend untuk database tugas kuliah.

## Fitur
- Login & register demo lokal
- Dashboard modern/glassmorphism
- Dark mode + light mode
- Animasi particles dan glow
- Animasi statistik counter
- Progress ring
- Tambah/edit/hapus tugas
- Checklist selesai
- Deadline & prioritas
- Search & sorting
- Responsive desktop/mobile
- localStorage per akun

## Menjalankan
1. Extract ZIP.
2. Buka folder di VS Code.
3. Jalankan `index.html` dengan Live Server atau buka langsung di browser.
4. Klik "Daftar sekarang" untuk membuat akun lokal.
5. Setelah itu login dengan akun tersebut.

## Penting tentang login
Login ini hanya untuk demo frontend. Username/password disimpan di localStorage dan BUKAN sistem autentikasi yang aman untuk aplikasi produksi.

Untuk versi sungguhan/online, gunakan backend + database seperti MySQL/PostgreSQL/Supabase/Firebase dan password hashing.
